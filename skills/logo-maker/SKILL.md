# Logo maker

Process distilled from the Stromal Therapeutics ("4C Facet" oxblood faceted heart) and Myney logo work. Logos are hand-built as SVG in code — geometric, simple, scalable — never generated images.

## 1. Brief (fast, no long questionnaire)
Start from what already exists: the company's website, deck, LinkedIn or a pasted description. Fetch it and extract:
- What the company does, in one plain sentence
- Who the logo must convince (investors, consumers, B2B buyers, distributors)
- The one idea the brand should carry (e.g. Stromal: the heart / inflammatory heart disease; Myney: found money, trust)
- Existing colors, fonts or marks worth keeping
- Market and language (Greek, Swiss, EU) and whether the name must work in Greek script
Only ask Ilia about what can't be found. Max 3 questions, in one message.

## 2. Three distinct directions
Always deliver 3 directions, each from a different angle — not 3 color variants of one idea. Typical spread:
- **Literal-symbolic**: the core object, abstracted (e.g. a faceted heart)
- **Abstract / conceptual**: the mechanism or benefit as form (flow, connection, growth)
- **Typographic**: wordmark-led, with one custom detail in a letter
Give each a short code name (like "4C Facet"). For each: one-line idea, why it fits the audience, palette (HEX), typeface (Google Fonts), and the risk.

## 3. Build
- Hand-code each mark as clean SVG: few paths, consistent stroke/angle logic, built on a grid
- Show each direction as: icon, wordmark, horizontal lockup — on light and dark, and at 16px favicon size
- Present all 3 side by side on one page (Design artifact type if available, otherwise an HTML artifact)

## 4. Test before showing
- Works in one color (black, white) and at 16px?
- Competitor test: could this mark belong to a direct competitor? If yes, sharpen it
- No category clichés (DNA helix, pill, generic swoosh, coin/€ sign, globe) unless deliberately subverted
- Doesn't resemble a known logo or character
- Name is legible and spelled correctly in the lockup

## 5. Iterate
Ilia picks one direction. Refine in tight rounds: one change set per round, show before/after. Stop polishing once it works — momentum matters more than perfection, especially in unsolicited pitches.

## 6. Final kit
Deliver SVG + PNG (transparent, 512px and 1024px):
- Primary horizontal lockup, stacked lockup, icon only, wordmark only
- Full color, mono black, mono white (reversed)
- favicon.svg + 32px/180px PNGs
- One-page mini guideline: colors (HEX/RGB, CMYK if print), fonts, clear space (= height of a defined element), minimum size (print mm / digital px), 4–6 don'ts
- A short brand block (colors, fonts, logo usage) ready to paste into a Lovable or v0 build prompt so the website uses the logo consistently

## 7. Portfolio version
If Ilia will show the work in his portfolio, also produce an anonymized presentation: keep the logo (his own work), remove client names, people and confidential details where needed.

## Style
Concise. Show the work, don't describe it. Opinion-first: say which direction is strongest and why.
